# gbm-multiomics-thesis

This repository contains the analysis code for a master’s thesis focused on the
benchmarking of unsupervised multi-omics integration methods in glioblastoma (GBM).

The study compares **MOFA2** and **Group Factor Analysis (GFA)** using paired
RNA-seq and promoter-level DNA methylation data derived from TCGA-GBM samples.
The main goal is to evaluate differences in latent factor structure, variance
decomposition, and biological interpretability.

---

## Repository Structure

The repository is organised to keep preprocessing, model fitting, and downstream
analyses clearly separated and reproducible.

### scripts/

Contains all analysis scripts.  
Scripts are intended to be run sequentially from the repository root.

- `00_setup_paths.R`  
  Central path configuration file.  
  Defines all input and output directories used across the project.

- `05_MOFA.R`  
  MOFA2 model fitting and downstream analyses using paired RNA-seq and
  promoter-level DNA methylation data.

- `06_GFA.R`  
  Group Factor Analysis (GFA) model fitting using the same paired inputs as MOFA2,
  enabling a controlled comparison between the two methods.

- `07_COMPARE.R`  
  Cross-model comparison of MOFA2 and GFA results, including functional enrichment
  overlap and intersection analyses.

---

### results/

Contains all outputs generated by the analysis scripts.

- `tables/`  
  Result tables from GSEA, ORA, and model comparison analyses.

- `plots/`  
  Figures generated for exploratory analysis, model evaluation, and reporting.

- `rds/`  
  Intermediate R objects saved during analysis.  
  Large fitted model objects are intentionally excluded.

---

### data_source/

Input data required to run the pipeline.  
This folder contains processed and harmonised omics matrices.
Raw data downloads and heavy preprocessing steps are performed externally and are
not included in this repository.

---

## Execution Order

All scripts should be run from the repository root in the following order:

1. `scripts/00_setup_paths.R`  
2. `scripts/05_MOFA.R`  
3. `scripts/06_GFA.R`  
4. `scripts/07_COMPARE.R`

---

## Reproducibility Notes

Large fitted model objects (e.g. full MOFA2 or GFA fit objects) are excluded from
version control to comply with GitHub file size limits.

The repository instead stores compact summary objects, result tables, and figures
required to reproduce all reported analyses and interpretations.
